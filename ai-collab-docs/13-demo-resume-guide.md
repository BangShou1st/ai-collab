## 2. 三分钟演示脚本

### 0:00–0:30 项目背景

说明竞赛资料分散、任务拆分遗漏和 AI 建议无法落地的问题。

### 0:30–1:10 普通协作

- 打开项目概览
- 展示角色和成员
- 展示任务看板、依赖和评论

### 1:10–2:00 知识库问答

- 上传比赛规则
- 展示 READY 状态

- 展示回答、引用和资料不足拒答

### 2:00–2:45 AI 任务规划

- 输入两周目标
- 生成结构化计划
- 修改一个任务和负责人
- 确认后展示正式里程碑与任务

### 2:45–3:00 工程亮点

展示 Docker Compose、测试报告、项目隔离用例和 AI 评测结果。

## 3. 简历项目名称

**基于 RAG 与结构化任务规划的高校竞赛 AI 协作平台**

## 4. 简历描述模板

以下数字必须用真实测试结果替换：

- 独立设计并实现面向高校竞赛团队的模块化单体协作平台，覆盖项目 RBAC、里程碑、任务依赖、评论、文档知识库和项目概览，并使用 Docker Compose 提供可复现的本地环境。
- 基于 Spring AI、PostgreSQL 与 pgvector 构建 RAG 链路，实现 PDF/DOCX/Markdown/TXT 异步解析、标题感知分块、项目级向量过滤和引用溯源；通过评测集对检索命中、拒答和越权场景进行验证。
- 设计多模型 `AiModelGateway`，支持手动切换免费 Chat Provider；将 Embedding 配置与文档索引绑定，避免不同向量空间混用，并记录模型耗时、Token 与错误码。
- 实现 AI 任务规划的结构化输出与两阶段校验，检测日期越界、非项目成员和循环依赖；用户确认后通过幂等接口在单事务中批量创建里程碑、任务与依赖。

## 5. 面试准备问题

1. 为什么选择模块化单体而不是微服务？
2. 如何保证不同项目的向量不会串数据？
3. 为什么 Chat Model 可以切换，Embedding Model 不宜直接切换？
4. 如何防止 AI 任务规划产生依赖环？
5. 文档删除时 MinIO 与数据库不一致怎么办？
6. 为什么不让模型直接调用创建任务工具？
7. RAG 如何判断资料不足？
8. 默认测试为什么不能调用真实模型？
9. 如何验证幂等确认没有重复创建任务？
10. 项目用户量很小时，Redis 和异步设计是否过度？
