# P9-RAG-GENERALIZATION-01 研究报告：旧冻结集质量数字的泛化价值

> 日期：2026-10-26　基线：`dev@3891171ecfc81a3929993f9f77989fed61ea5c85`
> 方法：独立合成语料（23 篇）+ 冻结评测题（39 题 / 54 条必答事实）+ 真实 Ollama/pgvector 双路径测量
> 原始数据：`docs/acceptance-evidence/2026-10-26/p9-rag-generalization-01/`

## 1. 研究问题

P8 收口时 QA 26/27、Agent 22/27 的关键事实保留率，究竟有多少泛化价值？当文档更长、版本更多、
证据更分散、问法更口语时，当前 RAG（不改动任何生产参数）能否稳定找到正确事实？

## 2. 方法要点与防泄漏设计

- **全新业务域**：设备维护、服务交接、资产盘点、审批与合同、技术变更、审计核对——与 P4 冻结集
  （发布/合同模板/导出/预算）无重叠；人名、数字、条款结构全部重新设计。
- **维度覆盖**：G01 长文档稀释（1k/3k/6k/1 万字 × 开头/中段/交界/尾部）、G02 跨文档组合（2–4 篇）、
  G03 同文档互补、G04 多版本冲突、G05 条件与例外（必须/建议/除非/且或/超时人工确认）、
  G06 相似文本不同来源（三份高相似盘点规范）、G07 无答案/未定/干扰/注入、G08 口语与同义改写。
- **dev/holdout 按文档族划分**（A/B/C ↔ D/E/F），holdout 文档与问题文件 SHA-256 先于测量冻结；
  本轮为纯基线测量，未依据任何集合的结果调整生产或评测参数，holdout 未被消费。
- **标签隔离**：marker 标注仅出现在离线评分 SQL；检索 query、来源选择、工具参数不含任何标注信息。
- **测量沿生产路径**：QA = search(8)+buildBalanced(5)；Agent = 真实执行 `KnowledgeSearchAgentTool`
  （候选池 20、limit 8、quote 600）；全量排序仅诊断。生产参数零改动、外部 Chat 零调用。
- **事实级定位口径**：一个事实由内容包含 marker 的全部 chunk 共同承载（首轮曾用单 chunk 定位，
  在重复段落语料上产生测量歧义——H-G07-UNDETERMINED "尚未确定"在 F3 出现两次导致一次假的
  RETRIEVAL_MISS，排查后固化为事实级口径并重测）。

## 3. 核心结果

| 指标 | 全集 | dev | holdout |
| --- | --- | --- | --- |
| QA 事实保留 | 52/54（96.3%） | 31/33 | 21/21 |
| Agent 工具摘录保留 | 51/54（94.4%） | 31/33 | 20/21 |
| Agent limit=12 对照 | 53/54（98.1%） | 32/33 | 21/21 |
| QA legacy 对照 | 53/54（98.1%） | 32/33 | 21/21 |
| 单题完整覆盖（QA / Agent） | 35/37、34/37 | 19/21、19/21 | 16/16、15/16 |
| Recall@8 / @20 | 98.1% / 100% | — | — |

失败全部为选择层（SELECTION_MISS 3 条）与 QA 召回层（1 条，全量排名 15）；
0 例 INDEX_MISS、0 例 BODY_TRUNCATION、0 例来源身份/范围违规。

### 3.1 与旧冻结集数字的对照

| 测试集 | QA | Agent(8) | 说明 |
| --- | --- | --- | --- |
| P4～P8 旧冻结集（同 SHA 重跑） | 26/27（96.3%） | 22/27（81.5%） | 逐事实零差异复现 |
| P9 独立集（dev+holdout） | 96.3% | 94.4% | 全新语料与措辞 |

两个直接结论：

1. **旧集 QA 26/27 的相对水平没有夸大 QA 路径**——同 SHA、同配置下，全新语料的 QA 保留率相同（96.3%），
   且 holdout 21/21 完全保留。QA 的"每文档名额均衡 + Top8 候选"在更长的文档、相似的来源、
   口语化问法上没有出现旧集之外的失效类型。
2. **旧集 Agent 22/27（81.5%）显著低估了 Agent 路径的泛化水平**——独立集上 Agent 94.4%，
   高出约 13pp。旧集的 Agent 失陷集中在"跨文档互补事实与固定 8 名额"的特定竞争结构上；
   换到新语料后同样的 8 名额表现好得多。**旧集是一个偏难的集合，而非偏乐观的集合。**

### 3.2 新暴露的失效机制（旧集不可见或方向相反）

- **代表饱和机制**（新发现的最普遍机制）：Top20 候选覆盖 ≥8 个文档时，`CrossDocumentSourceSelector`
  阶段一（每文档一个代表）直接占满 8 个名额，阶段二永不运行。同文档互补事实（即使全量排名第 2）
  被系统性挤出。G01-A4-BOUNDARY 与 H-G03-E3 两例的最终 8 来源均来自 8 个不同文档。
- **名额均衡（S2）反例**：G03-B2 同文档双事实场景，legacy（顺序选择）53/54 > balanced 52/54。
  P6 上线时旧集上 S2 无回归，该代价只有在"每文档多条必答事实"的新语料上才显形。
- **冲突条款暴露**：7 个干扰条款（旧版本、他中心、未审核来源）中 QA 6/7、Agent 7/7 被同时保留在
  最终可见上下文。现行版本辨别、废止条款识别、来源可信度判断全部留给生成端——本轮未测生成端。
- **诚实拒答压力**：2 道拒答题的干扰文档均进入工具摘录（工具语义为 RELEVANT_EXCERPTS_ONLY，
  不算缺陷，但意味着拒答判断完全依赖模型）。

### 3.3 Q02 类型问题的普遍性

旧集 Q02（目标证据全量排名第 23，无法进入正常候选）在新集 39 题中出现 1 例同族问题
（G02-B-3DOCS，排名 15）：QA Top8 召回不到，Agent 候选池覆盖到但名额饱和。
即：**Q02 类型不是孤例，但也不普遍（1/39），且新集上的瓶颈在名额而非召回**（Recall@20=100%）。

### 3.4 长文档稀释与措辞变化

- G01（11 题覆盖 1k→1 万字 × 四个位置）：QA 11/11。在 1200/150 分块下，长文档位置稀释
  未构成本轮任何一例失败；唯一 Agent 失败是名额机制（该事实排名全量第 4）。
- G08 改写（口语/省略/同义）：4/4 全保留（样本小，仅作方向性证据）。

## 4. 复现性

- 同 SHA 下第 2、3 次运行逐事实零差异；P6 旧集与 2026-10-25 历史基线（不同日期、不同进程）逐事实零差异。
- 唯一的跨运行差异来自首轮的 chunk 级定位歧义（见 §2），非嵌入服务方差；
  已在测量协议中排除（事实级定位 + ORDER BY chunk_no）。
- code points 不等于 token 数；quote 为 600 code point 前缀截断语义的测量复刻。

## 5. 对下一轮的建议（不实施）

1. `CrossDocumentSourceSelector` 阶段一名额上限实验（代表数 ≤6 + 强制阶段二），按 P6 D2 协议
   做逐题 gained/lost 与文档覆盖对照，并复测 P8 的覆盖反例。
2. `buildBalancedWithDiagnostics` 增加"同文档互补配额"，全量回归旧冻结集（P6 准入门槛）。
3. 把 P9 基准纳入每轮 RAG 改造的常规测量（旧集回归 + P9 dev 调试 + holdout 一次性行使），
   并继续扩充语料（多轮会话追问、表格型事实、跨语言混排为候补维度）。

## 6. 边界

- 真实 Chat 生成质量未测（`REAL_GENERATION_NOT_EXECUTED`）：所有"保留"结论止于
  实际进入模型上下文/工具摘录的事实，不构成回答正确性结论。
- 样本量（54 事实）下的比例数字有噪声；机制结论基于逐题归因而非平均值。
- 本轮测量与结论不构成任何生产变更的准入依据；未修改任何生产代码。
