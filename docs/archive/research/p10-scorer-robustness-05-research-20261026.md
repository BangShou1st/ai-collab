## 1. 静态风险真实复现与根因剖析

### 1.1 RISK-P10-008（阿拉伯数字编造候选检测与拒答冲突级联失守）
- **复现事实**：
  在当前基线上运行未修改代码，输入 `"资料不足，无法确认；但通常每年核对 50 份合同 [S1]。"`、`"资料不足，无法确认；但抽查比例通常为 5.5% [S1]。"` 与 `"资料不足，无法确认；但每年核对 1,200 份合同 [S1]。"`。
  实际输出：`unsupportedNumberCandidates` 均为空列表 `[]`，拒答判定为 `HONEST_ABSTENTION`，`abstentionCorrect = true`，高严重度告警完全为空。
  对比汉字数字 `"五十份"`（触发 `CONFLICTING_FABRICATION`），阿拉伯数字编造完全未被识别，证实静态风险存在。
- **根因分析**：
  `HAN_NUMBER` 正则为 `[零一二三四五六七八九十百千万]{1,10}(?:元|个工作日|个工作小时|小时|日|天|年|份|%|成)|百分之[零一二三四五六七八九十]{1,3}`，完全未收录 `\d+`、小数及千分位表达；在无答案题中导致伪造具体数字指标的行为能够披着拒答措辞的外衣直接通过。
- **技术推导与修复设计**：
  1. 扩展数字候选模式 `NUMERIC_CANDIDATE`，覆盖阿拉伯整数、小数（`5.5`）、百分比（`5.5%`）与千分位分隔符（`1,200`）；
  2. 实现预屏蔽机制，安全过滤非业务事实数字：
     - 来源引用编号：`[S1]`、`[S2]`；
     - 规范版本号：`V1.0`、`v2.0`；
     - 日期与年份：`YYYY-MM-DD`、`YYYY年MM月DD日`、`YYYY年`；
  3. 建立双向汉字/阿拉伯数字核心数值来源比对：
     - 若来源中包含阿拉伯数字（如 500）或汉字数字（五百），或属于题集预期事实与允许列表，判定为来源支持，避免合法数字误报；
     - 仅当数字未经来源支持且伴随拒答冲突时，触发 `CONFLICTING_FABRICATION`。

### 1.2 RISK-P10-009（富文本 HTML 标签剥离与删除线效力未知复核）
- **复现事实**：
  基线输入 `"通常<u>不可以</u>先组织培训再补签合同 [S1]。"`。
  实际输出：`forbiddenAffirmationDetails` 为空列表 `[]`！
  原因在于原句中 `不可以</u>先组织培训`，标签 `</u>` 插入在词语中间，导致 `indexOf("可以先组织培训再补签")` 返回 -1，禁断 marker 彻底脱漏。
  同时，输入 `"通常~~不可以~~先组织培训再补签合同 [S1]。"` 时，删除线同样造成匹配中断；若简单抹平删除线将其视为普通否定，将可能把说话人已经划掉作废的否定误当作有效否定放行。
- **根因分析**：
  `P10TextNormalizer.stripMarkdownFormatting()` 仅剥离粗体、斜体与代码块，未处理常见 HTML 展示标签（`<u>`、`<strong>`、`<em>`、`<span>` 等）；未区分删除线（代表撤回/作废）与强调标签的语义差别。
- **技术推导与修复设计**：
  1. 定义 `HTML_DISPLAY_TAG` 正则，多轮递归剥离成对及单闭合 HTML 展示标签，支持标签属性与任意层级嵌套；
  2. 针对删除线（`<del>`、`<s>`、`<strike>`、`~~`），统一定义为 Markdown 删除线 `~~text~~` 格式；
  3. 在 `P10ContextualAssertionJudge` 中建立删除线专属分流机制：
     - 当检测到 marker 或其紧邻修饰语处于删除线中（或局部子句包含 `~~`）时，将其判定为 `AMBIGUOUS_NEEDS_REVIEW`（“局部子句检测到删除线修饰，内容可能已被划掉或废止，语义效力存疑，转人工复核”）；
     - 若删除线出现在无关独立分句中（如“~~前期方案已作废~~，根据规定可以培训后补签”），则不影响后续独立肯定违规的正常检出。

### 1.3 RISK-P10-010（弱转折连词引导独立命题的作用域截断）
- **复现事实**：
  基线输入 `"资料中未明确具体比例只是制度要求每年抽查所有合同 [S1]。"`。
  实际输出：`verdict` 为 `NEGATED_OR_EPISTEMIC_MENTION`，高严重度告警为 0。
  原因在于整句无逗号标点，且 `只是` 未被识别为转折连词，左边界一直回退至句首 0，导致局部前缀包含了 `"未明确具体比例"`，滑入规则 E1 误判为合法未知表达，后半句独立肯定违规被完全放行。
- **根因分析**：
  `ADVERSATIVE_CONJUNCTION` 词表缺少对口语化及书面弱转折词（如 `只是`、`反倒`、`反而`、`相反`、`仅是`）的收录，导致在无标点连续文本中分句起点无法重置。
- **技术推导与修复设计**：
  1. 扩充 `ADVERSATIVE_CONJUNCTION` 词表，收录 `只是|反倒|反而|相反|仅是`；
  2. 在无标点复合句中，将局部子句起点截断至弱转折词处，彻底阻断前置分句认识模态的跨界传递；
  3. 严守边界：在版本限定与历史背景中，严格约束历史背景解释性语句（如“只是作为历史背景引用”）不被误判为现行违规。

## 2. 交叉交互与边界推导

三项加固在同一文本中复合出现时的交互推导：
- **HTML 标签 + 阿拉伯数字 + 拒答**：标签剥离必须先于数字抽取，确保 `<strong>50 份</strong>` 剥离为 `50 份` 后能被数字抽取器捕获并触发拒答冲突。
- **无标点弱转折 + HTML 标签包裹违规**：弱转折截断必须与富文本归一化协同，确保分句截断后能够完整匹配被标签包裹的禁断 marker。
- **删除线与弱转折**：删除线作用域限定在局部子句，转折连词切断后置分句，前置删除线不泄漏给后置独立命题。
