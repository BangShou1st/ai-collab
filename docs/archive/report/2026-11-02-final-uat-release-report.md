## 三、已知非阻断性环境特征与限制说明（P2/P3）

1. **公共免费模型通道限流特征（第三方上游限制）**：
   - 在高并发或公共额度耗尽时，第三方 OpenCode Zen Free 公共网关偶发返回 HTTP 429；
   - **系统防护机制验证良好**：系统能精确捕获该异常并映射为 `PLANNING_PROVIDER_QUOTA_EXCEEDED` 明确告知用户，且用户可在“AI 设置”中随时平滑无缝切换至官方备用网关（Kilo Gateway Free，推荐模型 `kilo-auto/free`）。该项不属于代码缺陷。
2. **多模态与超大文档索引建议**：
   - 知识库目前对纯文本与 Markdown 格式具备极高切分与命中率，文档上传通常在 2~3 秒内即变为“可检索”。
