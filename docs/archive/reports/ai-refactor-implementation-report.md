## 交付范围

### 模型与规划

- 新增 `PROMPT_JSON` 业务输出模式：规划骨架、详情与局部修复不再依赖提供商声明原生 JSON 能力；原生 JSON 请求仍遵守能力限制。
- 骨架、详情、局部修复解析拒绝尾随 JSON，仅整理完整成对 Markdown 围栏。格式修复有界，业务权限、成员、来源、骨架身份和锁定字段继续严格校验。修复输入携带原始目标、约束、基准及具体错误。
- 单次规划流程固定提供商配置；Agent 固定运行配置并持久化不含密钥的快照。运行中配置被编辑或取消授权时中止，不静默换模型。请求模式、有效输出预算和实际响应模型保留在日志/执行记录中；配置页快照表示请求配置，不能视为模型响应身份的证明。
- Zen 原生工具路径显式发送流式请求；取消“非流式请求失败后再发流式请求”的隐式重发。认证、限流、超时、截断、格式及业务错误分别处理。
- 生产 HTTP 客户端支持 SSE 多行事件、正文与工具参数分片、usage 缺失估算、完整终止检查、有限事件大小，以及流式/非流式请求的整体截止时间和取消。工具完整组装、严格解析后才进入执行器。
- 用户配置增加普通连通、提示词 JSON、流式、原生工具四种独立能力探测。每次只验证所选能力，工具探测仅校验合成调用，不执行业务工具。规划 JSON 探测验证最小合成结构，不等价于完整业务规划成功。

### Agent 工具、恢复与审批

- 工具结果区分成功、失败、拒绝、取消、跳过、未知；MCP 错误保留，失败结果不进入已验证事实。
- 先校验本轮暴露范围、工具权限、Schema 与协议身份。缺失/重复 callId 拒绝批次；持久化调用身份与提供商 callId 分离，同身份改变参数被拒绝。
- 只读调用使用应用管理的有界调度器；全局线程/队列上限 16/64，用户最多 4、运行最多 2 个执行许可。采用固定哈希分段信号量，哈希碰撞会保守降低不同用户/运行的并发，不会增加上限。内部工具和 MCP 使用各自超时，排队时间也计入调用截止时间。
- 批次先完成只读调用，再串行处理最多一个写入提案；多余提案明确拒绝，提案之后的只读调用不丢失。部分失败保留成功观察并展示实际完成范围。
- 模型重试、格式修复、参数纠正、工具重试独立持久化计数。工具重试要求模型再次请求相同失败调用、错误允许重试且尚有预算；不自动重做写入。模型最多两次恢复重试，格式修复、参数纠正、工具重试分别最多一次，并受总步数、令牌、工具与时间预算约束。
- 保存完整模型工具批次和调用账本，恢复时优先复用已知结果。提案创建/修订与调用绑定在同一事务；未知提案结果先查绑定，不盲目重新创建。
- Worker claim epoch、租约有效性及取消状态在提交事务中检查，旧 Worker 迟到提交被拒绝。主要模型完成、工具结果和运行状态事件与数据同事务提交；SSE 重连只回放事件。
- 类型化 `request_user_input` 澄清工具上线，兼容历史 `[QUESTIONS]`。保存原目标、最新补充、约束和待澄清问题；补充继续原目标，`/replace ` 或 `新目标：` 显式替换。
- 上下文保留有界历史与成对工具消息，并重新检查知识引用仍属于当前项目、文档可用；失效引用不再支持自动完成。提交模型前估算实际消息和工具 Schema 的输入令牌；没有 usage 时估算并标识。
- 审批 API 必填 `expectedRevision`，事务内检查所见版本、权限与参数；幂等记录同时检查审批人、nonce 和拒绝原因。前端按动作、版本和原因区分幂等键。
- 本进程取消会中断执行线程及在途传输；其他进程依赖数据库取消与租约检查拒绝后续提交。远端已接受的请求可能仍继续执行，不能承诺外部服务恰好一次或立即停止。
- 运行时间预算持久化实际执行时长，排队、等待用户输入和审批不计入；接管过期租约时结算上一执行区间。模型请求截止时间同时受运行剩余预算限制。

### Ollama、索引与 RAG

- 系统管理员 Embedding 页增加 Ollama 预设，使用 `/v1/embeddings`，允许免密钥。当前表单可先测试并探测自然维度，不能把默认 1536 当成所有模型的维度。
- 本地 HTTP 例外仅用于管理员 Embedding，受准确主机和端口白名单、DNS 地址及固定路径约束。聊天和 MCP 的公网 HTTPS 策略没有放宽；不支持将 `/api/embed` 送入兼容解析器，不跟随重定向。
- 更换提供商或目标地址不继承旧云密钥；同一目标普通编辑可以保留原密钥。验证向量数量、索引顺序、连续唯一索引、数值有限性及维度。认证/限流不重复请求。
- 查询向量、指纹和 generation 来自同一配置快照；文档写入在事务内再次验证快照及处理令牌，只有真正提交的成功/失败才发送对应通知。
- 新增候选索引代际：`QUEUED → BUILDING → READY → ACTIVE`，失败为 `FAILED`、旧索引为 `RETIRED`。候选构建期间原激活索引继续服务；激活必须显式操作，事务内核对配置、文档版本、覆盖范围和在途处理状态。构建中配置或文档改变时拒绝过时激活。
- 构建进度与项目批量重建进度保存在数据库，以真实文档状态统计排队、处理、完成、失败。服务重启后可读取；超过十分钟未更新的构建标记中断，原索引保留。
- 可显式清理失败、未激活或退休代际，禁止清理当前激活代际，最多保留三个失败/退休代际后要求先清理。清理旧向量会按既有外键规则删除关联历史引用，历史回答正文保留；管理界面操作前提示这一影响。
- RAG 使用有界近期问答上下文；连续追问结合上个用户问题检索，旧回答视为非证据。引用必须来自本次有效检索，无有效引用时返回证据不足。资料结论和模型推断在提示词中分开；问题长度前后端统一为 2000。
- 删除、撤销访问或文档不再 READY 后引用立即失效；保存答案前在事务中重新核对引用并锁定来源。流式断开取消任务，断开检测后不再保存答案；极短的断开与提交竞争仍属于最佳努力取消。
- 流式知识请求使用有界执行器，避免连接堆积。没有增加语义蕴含分类器：有效引用只能证明来源存在且可访问，不能自动证明回答每一句都被资料支持。

### 前端

更新用户模型设置、管理员 Embedding 管理、Agent 工作区与知识问答相关界面/API。Agent 展示实际工具状态、错误、提案、审批、等待输入、取消及配置/恢复快照；用服务端 invocationId 关联工具步骤，避免提供商重复 callId 合并不同调用。提案创建事件的 `RUNNING` 状态不再提前结束当前批次，兼容旧等待审批事件。没有增加模拟内部思考的展示。

## 可手动运行的真实 Smoke Test

在后端目录使用 PowerShell。测试只包含合成数据；执行前确认使用本项目授权配置，勿将密钥写进仓库、报告或聊天。

Ollama（服务与模型须已存在）：

```powershell
$env:AI_OLLAMA_SMOKE = 'true'
$env:AI_OLLAMA_SMOKE_MODEL = 'qwen3-embedding:0.6b'
.\mvnw.cmd -q '-Dtest=OllamaEmbeddingSmokeTest' test
Remove-Item Env:AI_OLLAMA_SMOKE
Remove-Item Env:AI_OLLAMA_SMOKE_MODEL
```

Zen：通过安全环境注入 `AI_ZEN_SMOKE_KEY`，再指定实际可用的模型；不从另一项目复制配置。

```powershell
$env:AI_ZEN_SMOKE = 'true'
$env:AI_ZEN_SMOKE_MODEL = 'mimo-v2.5-free'
.\mvnw.cmd -q '-Dtest=OpenCodeZenSmokeTest' test
Remove-Item Env:AI_ZEN_SMOKE
Remove-Item Env:AI_ZEN_SMOKE_MODEL
Remove-Item Env:AI_ZEN_SMOKE_KEY
```

Zen smoke 已在验收阶段增强：默认严格验证合成 JSON 正文契约；显式设置 `AI_ZEN_SMOKE_MODE=TOOLS` 时单独验证原生工具调用 ID、名称和参数，工具不执行。可以用 `AI_ZEN_SMOKE_KEY_FILE` 指定本项目授权密钥文件，避免聊天或命令行明文传递。任一模式只发一次请求，不能据此宣称完整规划已通过。遇到 401、403 或 429 停止本轮真实调用，先处理本项目配置或服务限额，不自动改模型或反复请求。本次已经遇到 403，未继续其他模式。
