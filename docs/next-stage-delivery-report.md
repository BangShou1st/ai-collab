### 关闭、兼容与恢复

新增记忆选择可用 `agent.context.relevant-memory=false` 恢复旧选择；`agent.context.composer-v2=false` 保留旧上下文路径，不能绕过预算与权限。文档和规划能力分别用前述开关关闭；`agent.enabled=false` 停 Agent 及其恢复调度。开关需要重启应用，正文表和操作记录保留；恢复时开启原开关，QUEUED 操作使用同 attempt 和已存范围继续，配置变更则明确失败，不重新生成第二份规划。RUNNING attempt 沿用原 stale recovery，不承诺恢复模型流的中间 token。
