# 被取代的全量尝试：agent.runtime-allowed=false

该尝试通过全局 runtime 开关关闭调度，但同时裁掉了 agentRunTaskExecutor 及其依赖的 Agent 业务 Bean，
导致 153 个 Spring 上下文错误。最终方案改为仅关闭 agent.scheduling-enabled，保留 runtime 与执行器装配。
