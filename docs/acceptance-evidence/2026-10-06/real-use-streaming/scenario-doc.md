# 星桥数据同步服务 发布值班手册(验收专用 20261006)

> 本文档为隔离验收专用测试资料,描述"星桥"数据同步服务的发布值班约定。
> 文档版本:v3.2,生效日期 2026-09-20,责任人:平台交付组。

## 1. 发布窗口

星桥数据同步服务的常规发布窗口固定在**每周三 02:00–02:30(UTC+8)**。
窗口期内执行灰度发布:先放量 10% 观察十五分钟,确认同步延迟指标无异常后再全量。

## 2. 回滚时限

发布开始后,如出现同步延迟超过阈值或数据校验不一致,**回滚操作必须在 15 分钟内完成**。
回滚采用数据库反向补录脚本,由值班工程师执行,回滚结果需在值班日志中登记。

## 3. 值班与审批

- 发布窗口值班工程师按周轮值,轮值表由平台交付组维护。
- 发布放行采用**三级审批**:模块负责人 → 平台交付组 → 值班经理。任一级驳回即中止发布。
- 紧急修复发布不受固定窗口限制,但需值班经理口头批准并在 24 小时内补记录。

## 4. 观察指标

灰度观察期间重点盯三项指标:同步延迟 P99、失败重试率、反向补录队列深度。
任何一项连续两个采样点超标,立即触发回滚流程。
