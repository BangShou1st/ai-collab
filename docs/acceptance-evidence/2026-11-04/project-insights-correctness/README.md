## AI 能力边界（如实声明）

- `/reports/weekly` 是**确定性统计接口，不调用大模型**——页面标题、描述与数据来源横幅均已如实标注
- AI 周报文字生成走协作 Agent 的 `WeeklyReportSkill`（对话式入口，复用同一 WorkReportService 事实数据），页面未伪造 AI 生成内容
- `WeeklyReportDraftAgentTool` 输出新增 startDate/endDate/periodStatistics（安全加法）
