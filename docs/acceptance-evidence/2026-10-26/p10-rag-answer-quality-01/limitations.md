# P10 限制与边界（limitations）

1. **无真实模型证据**：本轮未获外部 Chat 授权，全部"回答"为受控合成文本（脚本化模范/坏回答），
   仅验证评分器、引用契约与归因边界的正确性。`REAL_GENERATION_NOT_EXECUTED`。
2. **verbatim 代理**：事实覆盖以逐字 marker 命中为代理；同义改写会漏检（进 needsHumanReview）。
3. **禁断表述只能枚举**：否定翻转/地区套用/编造的机械检测仅覆盖题集枚举的措辞；
   变体措辞（如"允许先组织培训再补签"）不经枚举即漏检——语义级必须人工。
4. **P10 requiredMarkers 有 4 个超出 P9 逐事实标注**（加班记录/书面特批/二十万元/催办），
   其上下文可得性为 UNKNOWN，评分器如实标注而非臆断。
5. **离线评分的来源正文为语料全文（文档级）**，比真实 chunk 级上下文宽松；
   引用支持代理因此偏保守（高估支持率），语义支持结论以人工审查为准。
6. **Holdout 语义**：P9 Holdout 结果已可见，P10 作为冻结挑战集使用，非盲测。
7. **Agent 生成质量**：无授权即无真实 Agent 模型运行；本轮仅覆盖 Agent 引用身份的机械契约
   （真实 PostgreSQL 的 11 项既有契约测试继续默认执行）。
8. 一次 14 题的评测子集不覆盖全部风险面；扩展需新增题并重走冻结流程。
