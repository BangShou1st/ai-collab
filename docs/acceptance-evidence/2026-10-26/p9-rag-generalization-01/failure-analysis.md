## 2. 机制一：Agent 8 名额的"代表饱和"（本轮最重要的泛化发现）

`CrossDocumentSourceSelector` 两阶段选择：阶段一给候选池中每个文档一个代表 chunk，阶段二按全局相似度递补。
当 Top20 候选覆盖 ≥8 个文档时（23 篇语料的常态），**阶段一即占满全部 8 个名额，阶段二永远不运行**，
于是同文档的第二条互补事实、以及排名 9–20 之间的跨文档证据被系统性挤出。

证据：两例 Agent 失败的最终 8 个来源全部来自 8 个不同文档；
`agent12Stage`（53/54）显著优于 `agentStage`（51/54）；
旧冻结集上 P8 观察到的"固定 8 来源牺牲独立文档覆盖/互补事实"在本独立集上复现为普遍机制，
且方向相反的权衡同时存在：扩大名额能救回互补事实（+2），但会降低文档覆盖（P8 结论）。

这是名额约束的结构性问题，不是检索问题——两条失败事实的 Top20 排名分别为 4 和 2。

## 3. 机制二：QA 5 来源的"互补事实竞争"

G03-B2-COMPLEMENT 中，同一文档的两条必答事实（审批发起/复核 + 驳回处理）在 Top8 内排第 4/更前，
但每文档名额均衡选择（S2）只保留了其中一条；legacy（按候选顺序）两条都保留。
这是 S2 在"同文档互补事实"场景的明确反例：新集上 legacy 53/54 > balanced 52/54。
与 P6 上线时的评估相反（旧集上 S2 无回归），说明**名额均衡策略的代价在旧集上不可见**。

## 4. 机制三：跨文档复合问题的深排位证据

G02-B-3DOCS（3 文档复合题）的一条事实全量排名第 15：QA Top8 覆盖不到（RETRIEVAL_MISS），
Agent 候选池覆盖到但 8/12 名额被代表占满。这是旧集 Q02（排名第 23 无法进入候选）的同族问题，
但在新集中仅出现 1/39 且排名更浅（15 vs 23）——**Q02 类型问题不是孤例，但也不普遍**；
Agent 候选池 Top20 已能覆盖它，瓶颈在名额而不在召回。

## 5. 各维度结论（对应任务书的七个问题）

1. **长文档末尾事实是否更容易漏召回？否。** G01 维度 11 题：QA 11/11、Agent 10/11；
   约 1 万字文档的开头/中段/交界/尾部事实 QA 全部保留，唯一 Agent 失败是名额机制而非位置
   （该事实全量排名第 4）。当前 1200/150 分块下长文档信息稀释未构成主要失效。
2. **多文档代表选择是否稳定？基本稳定。** 2 文档题 8/8、4 文档题 5/5（QA 与 Agent 均）；
   3 文档题 2/3，失败即 §4 的深排位证据。
3. **同文档多条事实是否容易被丢弃？是，两条路径都会。** G03 维度 8 条事实丢 1（QA），
   Agent 侧同机制丢 2 条（§2/§3）。这是新集上最集中的失效类型。
4. **Agent 8 名额在哪类问题上最不足？** 同文档互补事实（G03）与章节交界长文档事实（G01），
   当候选池文档数 ≥8 时。
5. **检索问题还是裁剪问题？** 本轮 0 例 BODY_TRUNCATION（600 code point 截断未丢任何 marker）；
   全部失败是 RETRIEVAL_MISS（1 条）与 SELECTION_MISS（3 条）。候选池覆盖充分（Recall@20=100%）。
6. **条件句/版本/否定是否被截断破坏？否。** G05 5/5、G04 4/4 全保留。
   但冲突条款暴露率高：7 个干扰条款中 QA 6/7、Agent 7/7 同时保留在最终上下文
   （如 V1 旧标准 400 元与 V2 现行 500 元同时可见、已废止"不予报销"条款与新条款同时可见）。
   版本/冲突的辨别负担完全落在生成端（本轮未测，REAL_GENERATION_NOT_EXECUTED）。
7. **来源数增加是否一定更好？不是。** limit 8→12 在本集救回 2 条互补事实（+3.7pp），
   但 P8 旧集已证明更大名额会牺牲独立文档覆盖；名额、文档覆盖、互补事实三者存在结构性权衡。

## 6. 复现性与测量口径说明

- 同 SHA 下 run2 与 run3 逐事实零差异；P6 旧冻结集与 2026-10-25 历史基线逐事实零差异（REGRESSION_CLEAN）。
- 第 1 次运行（已废弃的 chunk 级定位口径）曾报告 H-G07-UNDETERMINED 全量排名 24；
  排查确认这是定位歧义而非嵌入方差——marker"尚未确定"在 F3 出现两次，无 ORDER BY 时定位到了
  另一个 chunk（事项四，排名 24）。事实级定位（本口径）固定为事项一（排名 1）。
  该事件说明**多 chunk 载体 marker 必须使用事实级定位**，已固化为测量协议。
- 无答案题的"干扰文档进入上下文"（H-G07-NONE/H-G07-INDIRECT）不判为缺陷：
  工具语义为 RELEVANT_EXCERPTS_ONLY（相关摘录 ≠ 答案存在），诚实拒答责任在生成端。
- 注入题（H-G07-INJECT）按 Q13 协议临时索引，工具输出身份与摘录核验通过；
  模型是否遵从"未经内部审核"事实并忽略嵌入指令属生成层，未测。
