# Phase 08 已知非阻塞限制

日期：2026-07-28

## 事件时间线的嵌套字段标签

- 当前行为：事件中的顶层字段可显示精确中文；`tasks.T1.startDate` 这类带实体路径的嵌套字段会回退为“相关字段”。
- 不阻塞发布：时间线仍显示事件类型、时间、目标和问题，且不影响版本内容、编辑、修复或确认。
- 可能影响：复杂变更的审计可读性略低，用户可能需要结合目标名称查看具体变化。
- 后续触发条件：用户反馈无法据此完成审计，或产品要求逐实体展示变更前后值时再完善路径解析。

## 普通生成 attempt 完成状态并非完全同事务

- 当前行为：版本、问题、事件和规划状态原子提交成功后，普通生成流程再单独把 generation attempt 标记为 `SUCCESS`。
- 不阻塞发布：规划版本和业务状态是权威结果；现有失败回滚测试覆盖版本、问题、事件和状态的一致性。
- 可能影响：进程在两次写入之间异常退出时，极少数 attempt 记录可能短暂保留非终态，影响运维统计而不改变规划数据。
- 后续触发条件：出现真实的悬挂 attempt、监控依赖 attempt 作为业务真值，或需要精确计费对账时再合并事务或增加恢复任务。

## 非关键代码清理和样式重构

- 当前行为：部分规划代码保留阶段性注释、较长组件和既有编译警告，本轮未做格式或架构重排。
- 不阻塞发布：目标测试、类型检查和构建覆盖生产行为，这些项目不改变数据或公开契约。
- 可能影响：后续维护成本略高，编译输出存在非阻塞告警。
- 后续触发条件：相关模块再次发生功能改动、CI 将告警升级为错误，或重复逻辑造成可复现缺陷时再定向清理。

## 已升级处理：预估工时边界

`0.1` 与 `0.5` 的差异会影响正式任务落库，因此不再作为已知限制保留。本轮已把规划校验下限与正式任务 DTO、数据库、OpenAPI 和前端统一为 `0.5` 小时，并增加 `0.49` 拒绝、`0.5` 接受的边界测试。
