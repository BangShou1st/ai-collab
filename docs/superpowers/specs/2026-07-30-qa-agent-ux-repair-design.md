# 知识问答与项目协作 Agent 可用性修复设计

## 目标

修复知识问答流式连接误报和页面滚动问题，完善项目协作 Agent 的会话与审批交互，移除无实际用户价值的 Agent 评估功能，让知识库评测与规划对比无需理解内部 ID 或 JSON 即可使用，并同步清理文档和更新当前功能状态。

## 范围

### 知识问答

- 保留 SSE 流式输出、逐段渲染和用户取消能力。
- 前端解析器兼容分片边界、CRLF、响应末尾没有空行、仅在数据对象中携带事件类型等合法流格式。
- 后端确保成功、业务错误和异常路径都只发送一次终止事件，再完成连接。
- 未收到终止事件时保留明确错误，但不得把已成功完成的合法响应误报为连接提前结束。
- 页面高度使用视口扣除应用导航后的剩余空间；页面外层不滚动，只有消息区滚动。
- 历史会话列表使用固定可视高度并独立滚动，会话数量少时不拉伸填满整页。
- 桌面端完整显示会话栏、对话区和输入区；窄屏允许合理降级。

### 项目导航与任务规划

- “任务规划”从“智能工具”下拉菜单移到一级项目导航。
- 顺序固定为“项目文档 → 知识问答 → 任务规划 → 协作 Agent”。

### 项目协作 Agent

- 会话新增重命名和删除操作；删除当前会话后选择下一条，没有会话时显示可直接新建的空状态。
- 后端增加会话重命名、删除接口，继续校验项目成员和会话归属。
- 删除 Agent“评估”页签、前端类型与请求、后端控制器、服务、仓储及不再使用的相关代码；已有数据库迁移历史不回写，必要时用新迁移移除只服务于该功能的表。
- 保留协作对话、待审批和定时运行。
- Agent 执行状态以中文用户语言展示，并继续轮询到终态；失败时保留重试入口。

### 审批展示

- 不直接展示原始工具名、内部状态或原始 JSON 差异。
- `create_task_after_approval` 显示为“创建任务”，其他工具通过集中映射显示中文业务动作。
- `PENDING`、`APPROVED`、`REJECTED`、`EXPIRED` 分别显示为“待审批”“已批准”“已拒绝”“已过期”。
- 创建任务提案显示任务名称、状态、截止日期、优先级、负责人、说明等用户关心字段；空字段显示“未设置”或直接省略。
- 任务状态和优先级均转换为现有中文业务标签。
- 审批按钮只在“待审批”状态出现。

## 知识库评测

- 保留知识库评测，因为它用于验证“问题能否检索到预期文档”，与 Agent 评估无关。
- 删除手工输入测试集 JSON 的交互。
- 页面允许逐条添加评测问题，并从当前项目已就绪文档中多选预期文档。
- 页面内解释指标：
  - Recall@3：预期文档是否出现在前三个检索结果中。
  - Recall@5：预期文档是否出现在前五个检索结果中。
  - MRR：正确文档越靠前，分数越高。
- 提交前校验问题非空、至少选择一个预期文档、至少存在一条用例。
- 评测历史与详情继续使用中文状态和百分比展示。

## 规划对比

- 页面进入时加载当前项目可用规划列表。
- 用户通过规划名称和版本选择要对比的规划，选择后加载对比结果。
- 若 URL 带合法 `planId`，自动选中；缺少或失效时展示选择引导，不再显示“请提供规划 ID”。
- 对比结果继续展示匹配、已修改、缺失和额外任务。

## 管理中心

- 管理中心现有范围保留：账号创建/启停、模型配置增删改测、知识问答/协作 Agent/任务规划模型分配。
- 补充管理员页面行为测试，验证仅系统管理员显示入口、主要交互调用正确接口、状态为中文。
- 更新功能矩阵中“尚无管理界面”“多模型仅配置”等过期描述。
- 修正文档中与实际权限校验冲突的旧注释或说明。

## 文档清理与实时状态

- 保留当前事实文档：架构、数据库、功能矩阵、OpenAPI、开发约定、冒烟测试和本设计说明。
- 删除已被当前事实文档替代的阶段学习稿、过期路线图、旧设计稿和旧实施计划。
- `feature-matrix.md` 只根据本轮验证后的代码事实标注“完整”“部分”或“未实现”，不得把存在代码但未验证的功能写成完整。
- OpenAPI 同步新增、删除和变更的接口。

## 数据流与错误处理

1. 用户发送问题后，前端创建临时助手消息并发起带认证信息的 SSE 请求。
2. 后端完成权限、会话、限流和文档范围校验后异步检索并调用模型。
3. token 事件增量更新临时消息；引用事件更新来源；done 事件触发持久消息刷新。
4. 业务错误通过 error 终止事件返回中文安全消息；网络中断才显示重试提示。
5. Agent 写操作仍必须经过审批，审批展示层只转换呈现，不改变后端审计、幂等键和 nonce 安全约束。

## 测试与验收

- 先为 SSE 末尾残留缓冲、CRLF、事件分片和终止事件兼容写失败测试，再修改解析器。
- 为 Agent 会话重命名/删除后端权限和前端交互写失败测试。
- 为审批中文摘要和状态映射写纯函数测试，避免测试原始模板文本。
- 为知识库评测表单转换、规划选择器和管理员主要交互写行为测试。
- 运行前端单元测试、类型检查和生产构建。
- 运行后端单元/集成测试与 OpenAPI 校验。
- 在可用本地依赖下执行知识问答流式请求和关键页面冒烟检查；若基础设施不可用，明确记录未执行项，不把它标为已验收。

## 非目标

- 不重做通用 Agent 架构。
- 不增加新的模型供应商。
- 不改变任务规划生成算法。
- 不删除知识库评测。
- 不修改已经在生产历史中执行过的旧 Flyway 迁移。
